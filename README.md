# IoT Monitoring Dashboard

A real-time IoT monitoring portfolio project for device telemetry, machine status, alerts, historical readings, and live operational dashboards.

## Project Goal

This project demonstrates an end-to-end IoT software architecture using Node.js, MQTT, WebSockets, REST APIs, device simulation, telemetry processing, testing, Docker, CI, and a responsive dashboard.

## Core Capabilities

- Real-time telemetry ingestion
- MQTT-ready device integration
- Built-in device simulator for public demos
- WebSocket live updates
- Device online/offline status
- Temperature, current, weight, and machine-state telemetry
- Alert generation
- Historical readings
- REST API
- Responsive monitoring dashboard

## Tech Stack

- JavaScript
- Node.js
- Express
- MQTT
- WebSockets
- PostgreSQL-ready persistence
- Zod
- HTML/CSS/JavaScript
- Docker
- GitHub Actions
